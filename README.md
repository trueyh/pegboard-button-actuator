# 洞洞板外置按键传动装置

本项目源于家庭热水设备开关键被洞洞板门遮挡的问题。设计者制作了一个PETG打印的机械传动装置，使使用者在门外按压，即可操作门内Benny面板最左侧的开关键。

这份记录整理真实设计、制作和使用经历，以及之后围绕TRIZ与可拓方法进行的讨论。它是经过整理的项目记录，不是原始AI聊天记录的逐字导出。整理日期：2026年11月14日。

## 最终结构

装置由内卡子、外卡子、外侧按钮和推杆四个打印零件组成，占用五个既有孔位。两侧卡子通过过盈连接夹住洞洞板，四个孔用于安装连接，中间孔供推杆通过。按钮与推杆分体制作，穿过导向孔后再过盈插接。

移动组件上的两处扩大部分不能通过导向孔，形成双向限位。总行程约3毫米，是设计估值。门关闭且未按压时，推杆头与原按钮微微接触；按压后触发，释放后借助原按钮的回弹返回。没有另装复位弹簧。
